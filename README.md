# Anthropic Economic Index Analysis

## Dataset

This project uses data from the **Anthropic Economic Index (AEI)**, specifically the September 15, 2025 Third Anthropic Economic Index Release.

The project uses two types of AEI data:

- Claude.ai usage data
- First-party API (1P API) usage data

The raw datasets cover the period **August 4, 2025 through August 11, 2025**.

## Research Question

**Do consumers and businesses use AI differently on the same tasks?**

This project compares patterns of AI use across Claude.ai and first-party API usage, focusing on task categories and collaboration patterns.

## Dataset Source

The dataset was obtained from Anthropic's official Anthropic Economic Index release and accompanying GitHub repository.

**Release:** Third Anthropic Economic Index Release, September 15, 2025

**Primary source:** Anthropic Economic Index
